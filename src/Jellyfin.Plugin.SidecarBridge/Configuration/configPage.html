Sidecar Bridge

External audio and subtitles from nested folders, connected with hardlinks during a normal library scan.

Enabled libraries / Библиотеки

Nothing is enabled by default. Original files stay in place. Filesystems must support hardlinks.

Optional absolute path on the Jellyfin server. Applies within enabled libraries, including subfolders.
Необязательный путь на сервере Jellyfin. Ограничивает обработку во включённых библиотеках этой папкой и её подпапками.


Cleanup is off by default. Source replacements update only links recorded as owned by this plugin.

Custom directory and language rules / Правила каталогов и языков

Optional. Built-in Audio, Sound, Subs, Subtitles and language prefixes work without regex. Rules use a 100 ms regex timeout. First matching rule wins. See the repository configuration guide.

Preview / Предпросмотр

Uses the current form values and makes no filesystem or registry changes.
